# Gmail email signature

Brand signature for Gordon / Buyer Perception, using Tom’s logo assets and the live palette.

## Files

| File | Purpose |
| --- | --- |
| `docs/email-signature.html` | Preview + two paste-ready signatures (open in a browser) |
| `public/images/email-signature-mark.png` | Cropped mark for the compact signature (28×50 display) |
| `public/images/email-signature-logo.png` | Cropped primary lockup (200×62 display) |

## Recommended layout

**Compact:** terracotta mark | Gordon / Founder / email / phone / site · Book a conversation

Uses charcoal `#252626` and terracotta `#B94E30`, table layout, Arial stack (Gmail-safe).

## Install

1. Deploy so `https://buyerperception.com/images/email-signature-*.png` are live.
2. Open `docs/email-signature.html` in a browser.
3. Copy the compact (or lockup) preview.
4. Paste into Gmail → Settings → See all settings → Signature → Save.
