How to install in Gmail

  1. Deploy so these assets are live:
    https://buyerperception.com/images/email-signature-mark.png
    https://buyerperception.com/images/email-signature-logo.png
  2. Open this file in a browser, select the signature preview you want, and copy it (Cmd+C).
  3. Gmail → ⚙️ Settings → See all settings → General → Signature.
  4. Create or edit a signature, paste (Cmd+V), save changes at the bottom.
  5. Send yourself a test from desktop and mobile. If the logo is missing, the image URL is not live yet.
